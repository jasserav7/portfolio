# Portafolio de Jasser Arrieta Villa

Sitio web personal de Jasser Arrieta Villa, Desarrollador de Software Full-Stack en Barranquilla, Colombia. Reúne su perfil, sus proyectos y un caso de estudio de Turnos.

Sitio: https://jasserav7.online

## Stack

Astro, TypeScript y Tailwind CSS 4. Sitio estático. Fuentes autoalojadas (Inter y Poppins con `@fontsource`) y `sitemap.xml` con `@astrojs/sitemap`.

## Cómo ejecutarlo

```bash
npm install
npm run dev       # servidor local
npm run build     # build de producción
npm run preview   # previsualizar el build
npm run check     # verificación de tipos
```

## Estructura

- `src/data/`: contenido (perfil, proyectos, stack y caso de estudio).
- `src/components/`: componentes de la interfaz.
- `src/pages/`: página de inicio, página 404 y caso de estudio.
- `src/layouts/`: diseño base con metadatos y SEO.
- `src/scripts/`: scripts pequeños de cliente (menú móvil, efecto de escritura, aparición al hacer scroll, sección activa y copiar correo).
- `public/`: CV, favicon, imagen Open Graph y `robots.txt`.
